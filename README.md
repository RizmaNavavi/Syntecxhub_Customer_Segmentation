# Syntecxhub - Customer Segmentation using RFM Analysis

## 📌 Project Overview
RFM analysis on an online retail dataset to segment customers into Loyal, Churn Risk, and New categories for targeted marketing.

## 🛠️ Tools Used
Python (Pandas, NumPy, Matplotlib, Seaborn), VS Code

## 📊 Methodology
1. Data Cleaning
2. RFM Calculation
3. Scoring (1–4 quartiles)
4. Segmentation (Loyal / Churn Risk / New / Others)
5. Visualization

## 💡 Marketing Recommendations
| Segment | Recommendation |
|---------|---------------|
| Loyal | VIP rewards program, early product access |
| Churn Risk | "We Miss You" email + 20% discount |
| New | Welcome series + discount on 2nd purchase |

## 📁 Files
- `rfm_analysis.py` — Main Python script

- `data/rfm_segments.csv` — Output RFM table
